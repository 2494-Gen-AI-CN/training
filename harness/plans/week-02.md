## Real-world framing and deliberate deviations

A support desk at a small software company runs on a codebase several people change every day. A customer files a ticket, an agent triages and assigns it, the SLA says how many hours each priority may stay open, and the team lead reads a weekly report: tickets per status, how long they took to resolve, which ones breached. The code behind that is a repository of modules with one job each, a virtual environment pinned by a lock file, a database for the tickets, logs shipped to a log service, a test suite that CI runs on every pull request, and a reporting job that draws the charts. This week builds a small version of each layer on purpose, in one folder on one laptop, and ledgers every shortcut below so the trainer can name it in one sentence when the room asks.
