## Notes

Deterministic by construction: render() reads no clock; today, next-up, overdue and readiness flags are computed in the browser from embedded dates (tracker.html?today=YYYY-MM-DD previews another day). Alarm rules: a day that is not live turns amber on the Wednesday before its week and red on the Friday before; a week without a passing plan turns amber 7 days and red 5 days before its Monday; a live day whose date has passed with no taught date turns amber the next day and red after 2 days; an open item is red when overdue and amber within 2 days; a thread chain break or an unresolved flagged run item is red. The Record agent uses the existing wire tier (haiku, low), so models.stages is unchanged; the week-plan workflow's agent cap rises from 4 to 5. Run id, token and duration figures are invisible to a workflow script, so the session adds them with log_run.py amend. When trainer/ is absent the build refuses to write and the staleness test skips.
