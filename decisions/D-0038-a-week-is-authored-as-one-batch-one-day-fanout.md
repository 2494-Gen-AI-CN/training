# D-0038 — A week is authored as one batch: one day-fanout invocation takes the teaching days of a week, researches them in parallel, authors their demos strictly in day order (each rung starts from the previous rung's key on disk), then writes notes, exercise and runbook for all days in parallel; a day whose demos stage produces no scripts blocks the later days of that run instead of letting them build on a missing key; pages written in the same run link forward to each other; single-day runs stay valid. Target cadence: every artifact of week N is authored by the close of week N-1, and each delivery day ends with a close audit against the classroom repo

- Date: 2026-10-12
- Status: accepted
- Decision: A week is authored as one batch: one day-fanout invocation takes the teaching days of a week, researches them in parallel, authors their demos strictly in day order (each rung starts from the previous rung's key on disk), then writes notes, exercise and runbook for all days in parallel; a day whose demos stage produces no scripts blocks the later days of that run instead of letting them build on a missing key; pages written in the same run link forward to each other; single-day runs stay valid. Target cadence: every artifact of week N is authored by the close of week N-1, and each delivery day ends with a close audit against the classroom repo
- Why: The target is a whole week authored before it starts, not a day authored the evening before. The script ran the days of a multi-day run in parallel, which breaks the demo-thread order of D-0033: Thursday's first rung needs Wednesday's last key on disk. One invocation per day (D-0008) also meant three or more supervised runs per week and pages that could not link forward until the next day shipped.
