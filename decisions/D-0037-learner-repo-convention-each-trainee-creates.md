# D-0037 — Learner repo convention: each trainee creates one private repository named FirstnameLastname inside the 2494-Gen-AI-CN organisation in the W1D2 Git exercise and keeps it for the whole course (exercise hand-ins under week-dir/day-slug, code-along in one folder per demo thread, scratch for explorations); it replaces the per-day public w01d2-team-repo under a personal account; config.json learnerRepo records the convention and reaches every exercise and runbook author and critic prompt; the trainer's demo-thread repo keeps the name team-repo

- Date: 2026-10-12
- Status: accepted
- Decision: Learner repo convention: each trainee creates one private repository named FirstnameLastname inside the 2494-Gen-AI-CN organisation in the W1D2 Git exercise and keeps it for the whole course (exercise hand-ins under week-dir/day-slug, code-along in one folder per demo thread, scratch for explorations); it replaces the per-day public w01d2-team-repo under a personal account; config.json learnerRepo records the convention and reaches every exercise and runbook author and critic prompt; the trainer's demo-thread repo keeps the name team-repo
- Why: A throwaway repo per day leaves trainees with no single place for code-along copies, solo exercises and explorations, and the catalog (C4) already flagged the missing learner-repo convention. One repo in the org lets the trainer clone and mark every trainee from one place. Private because the repo lives through the key-gated weeks 5 to 11 (a leaked key in a public repo is scraped in minutes) and because a public repo named after a trainee exposes their name and commit e-mail; with org base permission None it also stops trainees reading each other's solo work. Team repos come later and are a separate decision.
