Working in pairs, find a publicly available dataset, analyse it and draw inferences from it with Python, pandas and Matplotlib. Pairs were assigned in class.

## Dataset

- Size: large. Aim for 100,000 rows or more.
- Type: real data preferred; synthetic data is allowed.
- Restrictions: non-sensitive only. No crime, demographics or similarly sensitive topics.

## Rules

- All analysis and visualisation code (Python, pandas, Matplotlib) is written by hand. Jupyter notebooks are allowed.
- AI tools may only generate a front end that presents your code and charts (for example a Streamlit page or slides). They do not write the analysis.

## Presentation

- When: Monday 26 October 2026, in class.
- Length: about 20 minutes per pair.
- Format: your choice. A Jupyter notebook, a Streamlit app, slides, or similar.
- Both partners speak.
- Walk through the code live, not a screenshot of it.

## Hand-in

Push to `week-02/hackathon/` in one partner's learner repository before the presentation: the notebook or scripts, the charts as image files, a link to the dataset (not the data file itself when it is large) and a short README that names the other partner's repository.
