Where each criterion is taught

Week 3 · Day 1 — SQL & RDBMS introduction

  • qc2.sql.R01 Required Articulate the reasons for using a Relational Database Model to represent data.
  • qc2.sql.P02 Preferred Read and understand ERD (Entity Relationship Diagram)
  • qc2.sql.P04 Preferred Accurately describe database schemas, including tables, fields, and the relationships between them.
  • qc2.sql.P05 Preferred Identify and implement common data types such as varchar, decimal, integer, and char.
  • qc2.sql.P06 Preferred Translate real-world problem descriptions into ER diagrams and implement them as a working relational schema.

Week 3 · Day 2 — SQL sublanguages

  • qc2.sql.R02 Required Explain the usage of the sublanguages in SQL
  • qc2.sql.R04 Required Construct SQL statements using DDL (CREATE, DROP, ALTER, TRUNCATE) keywords to create, alter, drop, and truncate tables
  • qc2.sql.R06 Required Construct SQL statements using DML (INSERT, UPDATE, DELETE) keywords to manipulate pre-existing data within tables
  • qc2.sql.R07 Required Describe the difference between DROP, DELETE, and TRUNCATE functionality
  • qc2.sql.S01 Stretch Explain how to modify a table structure after creation using ALTER TABLE with examples (e.g., adding a column, modifying a data type).

Week 3 · Day 3 — Keys, constraints & normalization

  • qc2.sql.R03 Required Understand the role of a primary key in a data-set.
  • qc2.sql.R05 Required Describe and utilize constraints in table creation. (Unique, Not Null, Primary Key, Foreign Key, Auto Incrementing, Default, Check)
  • qc2.sql.R08 Required Understand the role of a foreign key in a data-set.
  • qc2.sql.R09 Required Create a valid schema for a given data-set
  • qc2.sql.R15 Required Normalize a database schema from unnormalized form (0NF) to Third Normal Form (3NF), providing step-by-step justification.
  • qc2.sql.R16 Required Describe referential integrity
  • qc2.sql.P01 Preferred Demonstrate how to identify valid candidate keys for a primary key of an entity
  • qc2.sql.P03 Preferred Explain the concept of multiplicity in database relationships.
  • qc2.sql.P08 Preferred Explain the benefits and potential drawbacks of database normalization, including impacts on performance and data integrity.
  • qc2.sql.P09 Preferred Utilize cascades to define what happens to related tables during DML operations
  • qc2.sql.S02 Stretch Recognize and explain less common key types beyond primary and foreign keys, such as candidate keys or composite keys.
  • qc2.sql.S03 Stretch Identify and implement advanced data types beyond the basics, such as BIGINT for handling very large integers
  • qc2.sql.S04 Stretch Capable of implementing bridge tables to handle many-to-many relationships between entities.

Week 3 · Day 4 — Joins, subqueries & transactions

  • qc2.sql.R10 Required Describe the purpose of transactions in a database and when they are used.
  • qc2.sql.R11 Required Understand database consistency and utilize transactions to ensure data consistency in a set of SQL commands.
  • qc2.sql.R17 Required Explain the ACID properties (Atomicity, Consistency, Isolation, Durability) and their importance in transaction management.
  • qc2.sql.R18 Required Understand the difference between aggregate and scalar functions
  • qc2.sql.R19 Required Utilize the GROUP BY clause.
  • qc2.sql.R20 Required Demonstrate the ability to filter records using the WHERE clause and operators
  • qc2.sql.R21 Required Understand basic types of joins and demonstrate usage in select statements (inner, left/right outer, full outer, equi)
  • qc2.sql.P07 Preferred Identify and compare different isolation levels (Read Uncommitted, Read Committed, Repeatable Read, Serializable) and their trade-offs.
  • qc2.sql.P13 Preferred Utilize the HAVING clause to filter aggregated query results
  • qc2.sql.P14 Preferred Understand when to use subqueries versus joins in SQL logic
  • qc2.sql.P15 Preferred Identify and use commonly used aggregate functions (e.g., COUNT(), SUM(), AVG(), MIN(), MAX()) to summarize data in queries.
  • qc2.sql.P16 Preferred Utilize column aliases to enhance readability and clarity of SQL queries.
  • qc2.sql.S05 Stretch Understand and know how to utilize Window Functions
  • qc2.sql.S06 Stretch Utilize Common Table Expressions (CTEs)
  • qc2.sql.S07 Stretch Utilize subquery structure to execute a select statement.
  • qc2.sql.S08 Stretch Utilize set operations between multiple select statements

Week 3 · Day 5 — Advanced SQL: triggers, views, procedures & indexes

  • qc2.sql.R12 Required Be able to create a User Defined Function
  • qc2.sql.R13 Required Be able to create and call a Stored Procedure
  • qc2.sql.R14 Required Create and use views to store the results of a SQL query
  • qc2.sql.P10 Preferred Configure triggers to execute the corresponding stored procedures when certain events occur
  • qc2.sql.P11 Preferred Describe database indexing and its benefits
  • qc2.sql.P12 Preferred Describe triggers and their use in automating tasks.
