Exit criteria

Revature publishes, for each technology group of the course, the list of things a learner should be able to do or explain when the group ends. Each page below is that list for one group, with a tick box per row and a link to the day of notes where it is taught.

How to read the tiers

Required, Preferred, Stretch

Required rows are expected of everyone at the group's exit. Preferred rows are what a strong learner can also do. Stretch rows go beyond the course: good to know, never assumed.

The mock interview and the exam at the end of each group draw from these rows, so use the checklist as a revision list: open a row's day of notes, work through it, then tick the row. Ticks are saved in this browser only (nothing is sent anywhere), so they are yours to clear and redo.
